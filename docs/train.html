Local GPU Trainer

Train D'QUILANE pakai GPU kamu sendiri (RTX 3050 4GB+)

🚀 Cara Kerja

Download local trainer, jalankan di komputer kamu. Script akan otomatis: deteksi Python → install torch+CUDA → train di GPU → start local web UI buat test.

GPU cuma kepake pas training. Setelah selesai, GPU balik idle (RAM & VRAM bebas).

d=192, n=16

~700K
2000
Epochs
~5-15 min
Waktu (GPU)

📥 Step 1: Download Files

Download semua file berikut ke satu folder (mis: C:\dquilane):

  • 📄 setup.bat — auto-install Python deps + torch+CUDA
  • 📄 train.bat — train model di GPU kamu
  • 📄 serve.bat — start local web UI buat test
  • 📄 dquilane_local.py — training script (Python)
  • 📄 corpus_v010.py — dataset
  • 📁 web/ folder — UI files

⬇ setup.bat ⬇ train.bat ⬇ serve.bat ⬇ dquilane_local.py ⬇ corpus_v010.py

⚙️ Step 2: One-time Setup

Klik 2x setup.bat atau jalankan di Command Prompt:

cd C:\dquilane
setup.bat

Script akan:

1
Cek Python (install kalau belum, atau pakai yang ada)
2
Buat virtual environment (venv) di folder
3
Install PyTorch dengan CUDA support (untuk GPU kamu)
4
Install numpy

One-time only. Kalau sudah selesai, langsung loncat ke Step 3 tiap mau train.

⚠️ Troubleshooting

Python belum ke-install?
Download dari python.org, install dengan centang "Add to PATH". Setelah itu run setup.bat lagi.
GPU gak ke-detect?
Pastikan NVIDIA driver terbaru. Run nvidia-smi di cmd buat cek. Kalau muncul GPU info, berarti OK.
Out of memory (OOM)?
Edit dquilane_local.py, turunkan batch_size dari 32 ke 16. Atau d_model dari 192 ke 160.
Setup gagal?
Run manual: python -m venv venv lalu venv\Scripts\activate lalu pip install torch --index-url https://download.pytorch.org/whl/cu121

🔄 Update Model ke GitHub Pages

Setelah train lokal, model baru ada di web/dquilane_model.json. Buat update production:

  1. Copy file web/dquilane_model.json ke folder repo GitHub kamu di docs/
  2. Git commit & push: git add . && git commit -m "update model" && git push
  3. Tunggu 1-2 menit, production auto-update
