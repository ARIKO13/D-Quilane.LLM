# D'QUILANE TK v0.5 — Multilingual LLM

Multilingual LLM dibuat dari nol. **30+ bahasa dengan native script**, **TK level**, dengan **SFT fine-tuning** support.

## 🆕 What's New in v0.5 (TK)

- **Upgrade balita → TK**: d_model 128→144, virtual depth 8→10
- **Sampling baru**: Top-p (nucleus), Repetition penalty, max 1000 tokens
- **SFT (Supervised Fine-Tuning)**: cell di Kaggle notebook buat instruction following
- **UI frontier LLM**: ChatGPT-style, sidebar settings, presets
- **In-context learning**: Custom knowledge box di web UI
- **30+ bahasa** dengan native script (Latin, Cyrillic, CJK, Hangul, Arabic, Devanagari, Bengali, Thai, Greek, Hebrew)

## 🚀 Cara Update Model

1. Edit `kaggle/dquilane_global.ipynb` (ubah corpus/config/SFT examples)
2. Upload ke Kaggle → Run All
3. Download `output/dquilane_model.json` dari tab Output
4. Replace `docs/dquilane_model.json` di repo ini
5. Push ke main → GitHub Pages auto-update (1-2 menit)

## 🧠 Architecture

- **Transformer decoder** (GPT-style) dari nol
- **Parameter sharing** (ALBERT-style): 1 block dipakai 10x (virtual depth 10)
- **SwiGLU** FFN
- **RMSNorm** (lebih hemat dari LayerNorm)
- **Weight tying**: output head = token embedding
- **Char-level tokenizer** (handles any unicode)
- **Sampling**: temperature + top-k + top-p + repetition penalty
